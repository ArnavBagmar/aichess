How to read this

The score is the net's evaluation in centipawns, shown from White's side; internally the search keeps it as an integer in 1/32-centipawn units. Depth is the last iteration that finished inside the think time; the table lists them all, with the node count when each one completed. Nodes include the quiescence search at the leaves, which is why depth 1 already costs hundreds of nodes. The transposition table holds 220 entries and survives across moves within a game, so later moves start with knowledge. The principal variation is read back out of that table after the search, which is why it can be shorter than the depth.
